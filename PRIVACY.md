# Privacy

RouteLab has no account system, analytics SDK, telemetry endpoint, cloud sync, or automatic update service. Practice and rubric feedback run locally. The app does not automatically send typed routes or study history anywhere.

The app saves review history, timestamps, timings, self-ratings, and the submitted route to `progress.json` beside the executable after self-rating. A `.bak` file preserves the previous save. Do not publish these files. Deleting them resets that local history; keep a private backup if you want to retain it. Closing the app discards unsaved text.

Source links open AoPS in your browser. Donate opens Stripe; Ko-fi opens Ko-fi. These sites apply their own privacy and payment policies and may receive normal browser/network information. RouteLab does not receive card details or process the checkout. Payments are optional and do not unlock features.

Public payment/profile links identify the publisher's public accounts. Neither those links nor GitHub hosting provide anonymity. Existing copies of older releases or information held by third-party providers cannot be erased by cleaning this package.

The release is assembled from an explicit file list. It contains no saved routes, progress backups, developer screenshots, raw page exports, debug symbols, machine usernames, absolute home-directory paths, or private source code.
